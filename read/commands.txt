3. User-Defined Data TypesCustom types defined by the user:
* Structure (struct): Groups different data types together.
* Union (union): Similar to structures but shares the same memory for all members.
* Enumeration (enum): Defines a set of named integer constants.
* Typedef: Defines an alias for an existing type.
* short/long: Adjusts the memory allocation size.
